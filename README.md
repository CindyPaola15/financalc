FinanCalc

FinanCalc es una aplicación web de simulación financiera desarrollada con React, JavaScript y CSS. Su objetivo es facilitar cálculos financieros básicos y ayudar a los usuarios a conocer montos, intereses, cuotas y proyecciones de ahorro.

Funcionalidades

La aplicación incluye cuatro tipos de cálculos financieros:

* Préstamos: calcula una cuota mensual estimada, los intereses y el total a pagar.
* Interés simple: calcula los intereses generados sobre un capital inicial durante un período determinado.
* Interés compuesto: estima el monto acumulado mediante la capitalización mensual de los intereses.
* Ahorro: proyecta el crecimiento de un depósito inicial según la tasa de interés y el plazo seleccionados.

Además, incluye validación de datos, mensajes de error, un botón para limpiar el formulario y una interfaz adaptable a dispositivos móviles y computadoras.

Tecnologías utilizadas

* React
* JavaScript
* Vite
* CSS
* Hooks de React (useState)

Requisitos

Para ejecutar el proyecto localmente, es necesario tener instalado Node.js.

Instalación y ejecución

Sigue estos pasos para ejecutar FinanCalc en tu computadora.

1. Descarga o clona el repositorio desde GitHub.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:

npm install

4. Inicia el servidor de desarrollo:

npm run dev

5. Abre en el navegador la dirección local que aparece en la terminal.

Instrucciones de uso

1. Selecciona el tipo de cálculo que deseas realizar.
2. Introduce el capital o monto inicial, la tasa de interés anual y el plazo en años.
3. Pulsa Calcular resultado para visualizar la estimación.
4. Consulta el resultado principal y el desglose de la operación.
5. Utiliza el botón Limpiar para borrar los datos y realizar otra simulación.

Consideraciones sobre los cálculos

Los resultados son estimaciones basadas en los datos introducidos por el usuario.

* Los préstamos se calculan mediante cuotas mensuales y no incluyen posibles seguros, comisiones ni otros cargos adicionales.
* El interés simple se calcula sobre el capital inicial.
* El interés compuesto utiliza capitalización mensual.
* La proyección de ahorro considera un depósito inicial, sin aportaciones periódicas adicionales.

Los resultados pueden variar según las condiciones reales de cada producto financiero.
